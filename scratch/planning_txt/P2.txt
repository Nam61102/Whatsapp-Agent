4. Message retention

I wouldn't delete everything older than 15 days immediately.

Better architecture:

0–15 days

    ↓

Full messages + media metadata

    ↓

AI processing

    ↓

Important information extracted

    ↓

15+ days

    ↓

Delete raw message/media data

    ↓

Keep AI summaries/extractions

So you might have:

Raw messages       → 15 days

Media              → 7–15 days

Conversation summary → long-term

AI extractions     → long-term

Contact profile    → long-term

But give the user settings:

Message retention

○ 7 days

● 15 days

○ 30 days

○ 90 days

○ Forever

For privacy, I'd make 15 days the default.

13. Most important security rule

Every API request must resolve:

JWT

 ↓

user_id

 ↓

whatsapp_account_id

 ↓

resource

Never do:

SELECT * FROM messages WHERE conversation_id = ?

by itself.

Instead:

SELECT m.*

FROM messages m

JOIN conversations c

  ON c.id = m.conversation_id

WHERE m.conversation_id = $1

AND c.whatsapp_account_id = $2;

This is what prevents:

User A

❌ seeing User B's messages

Even if someone manipulates an ID.

One change I'd strongly recommend

Don't build the AI as:

Every message → send entire chat → AI

That becomes expensive and slow.

Instead:

New message

     ↓

Queue

     ↓

Lightweight classification

     ↓

Is it important?

     ├── No → store

     │

     └── Yes

          ↓

      extraction

          ↓

      update contact profile

          ↓

      update conversation summary

          ↓

      generate reply context

For replies:

Last 20–50 messages

        +

conversation summary

        +

contact AI profile

        +

relevant extracted memories

        ↓

      AI

        ↓

3 reply suggestions

That gives you much better cost, speed, privacy, and scalability than sending the entire chat history to the AI every time.

If you're going to actually start coding this, the next thing I would create is the complete PostgreSQL/Prisma schema + all NestJS API routes/controllers/services + React Native API/socket structure, rather than just a high-level design.
